Bro, THIS is exactly the research question of your project. You're asking the right thing.

You are asking:

"On what basis does the scheduler choose Zstd, Brotli, Gzip or LZ4?"

It cannot choose randomly. There must be a scientific basis.

Answer

The scheduler selects the compression algorithm based on the features extracted from the message and the expected reward (or cost) learned during training.

Think of it like this.

Step 1: Extract Features

For every message:

Message:
"Hello everyone, today's meeting starts at 10 AM."

Extract:

Feature	Value
Character Length	48
Token Count	9
Entropy	3.8
Repetition Score	0.10
Arrival Rate	120 msg/sec
Emoji Ratio	0
Unique Word Ratio	0.95

These become the input to the scheduler.

Step 2: During Training

The scheduler tries every codec on the same message.

Example:

My Recommendation

If I were publishing this paper, I would not hard-code any rules like:

Long text → Brotli
Short text → Zstd

Instead:

During training, run every message through all four codecs.
Measure compression ratio, latency, CPU usage, and memory.
Compute a utility score for each codec.
Label the message with the best-performing codec.
Train the bandit to predict that optimal codec from the extracted features.
